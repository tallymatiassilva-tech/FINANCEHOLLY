# Controle Financeiro Igreja

Aplicativo Flutter offline-first para gestão financeira de igrejas.

O projeto-fonte completo, pronto para extrair e abrir no Flutter, está no arquivo `PIRITUBA-APP-source.zip` neste repositório. O APK Android para instalação está disponível na área **Releases**.

Os dados ficam armazenados localmente no aparelho. Trate os arquivos de backup como informação financeira confidencial.

## Plataformas

- Android: gere com `flutter build apk --release`.
- iOS: compilação requer macOS, Xcode e assinatura Apple.
